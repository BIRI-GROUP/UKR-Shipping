# Fleet & Dispatch

Each vehicle record stores identity, ownership, plate, photos, body/internal dimensions, door opening, payload, CBM/pallet capacity, equipment, restrictions, documents/expiries and eligible drivers.

Before assignment, validate:
- payload
- cargo dimensional fit
- door/deck fit
- DG/temperature capability
- loading/offloading equipment
- route/permit eligibility
- vehicle/driver document validity

Wrong-equipment assignments should be blocked unless an authorized override rule explicitly permits them with a recorded reason.
