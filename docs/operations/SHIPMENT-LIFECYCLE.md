# Shipment Lifecycle

Inquiry → Qualification → Estimate/Quote → Acceptance → Booking → Origin Arrangement → Pickup/Gate-in/Warehouse Receipt → Measurement/Verification → Consolidation/SmartLoad (if applicable) → Carrier Acceptance → Export/Origin Customs → Loaded/Departed → In Transit → Arrived → Import Customs/Customer Action → Released/Collected/Gate-out → Offload/Sorting (if required) → Delivery Assignment → Out for Delivery → Delivered/POD → Invoice/Payment/Reconciliation → Close → Feedback → KPI.

Each service product activates only the milestones it needs.
Customer-facing events can trigger portal/email notifications.
