# UKR-Shipping

UKR Shipping Trade & Logistics Platform.

## Project surfaces
- Public website integration
- Staff operations platform
- Customer portal
- Central API and business rules
- Background workers
- Operational database
- End-to-end tests

## Core principles
- Preserve important existing UKR website URLs.
- One UKR Shipment ID links the full shipment lifecycle.
- Customer and staff experiences share one controlled data model.
- Internal buy rates, margins and private notes are never customer-visible.
- Routes, services, questions, documents, rates and workflows are configuration-driven.
- Development and staging are separated from the live WordPress website.
